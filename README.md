# البوابة الإلكترونية لثانوية حسين محمد الصغير – سيدي داود

موقع عام باللغة العربية، متوافق مع GitHub Pages، يخدم الأخبار والأنشطة والوثائق وأرشيف النتائج العامة.

## تشغيل الموقع
افتح `index.html` محليًا للصفحات الثابتة. لعرض بيانات JSON في المتصفح شغّل خادمًا محليًا، مثل `python -m http.server 8000` ثم افتح `http://localhost:8000/`.

## إضافة محتوى
توجد قوائم المحتوى في:
- `data/announcements.json`: الإعلانات
- `data/activities.json`: الأنشطة
- `data/documents.json`: الوثائق

صيغة السجل:
```json
{
  "title": "عنوان المادة",
  "date": "2026-10-15",
  "category": "عام",
  "summary": "وصف موجز",
  "url": "https://example.org/document.pdf",
  "published": false
}
```
يجب استبدال الرابط بمصدر معتمد. بعد التحقق من صحة المعلومات وموافقة الجهة المخولة، غيّر `published` إلى `true`. لا تُنشأ أخبار أو إعلانات وهمية في الموقع. يقبل الحقل `url` روابط http(s) فقط، ويمكن تركه فارغًا.

## التنقل
- `index.html`: الرئيسية
- `about.html`: من نحن
- `announcements.html`: الإعلانات والبحث والفلاتر
- `results.html`, `results-2025.html`: أرشيف البكالوريا العام
- `activities.html`: الأنشطة
- `students.html`: فضاء التلميذ
- `documents.html`: الوثائق
- `contact.html`: اتصل بنا
- `privacy.html`: سياسة الخصوصية

## تنبيهات الخصوصية
كان الإصدار القديم يحتوي في `index.html` على بيانات شخصية ونتائج فردية لطلبة 2025. النسخة الحالية لا تعرض تلك البيانات. لكن **إزالة المحتوى من آخر إصدار لا تمحو سجل Git أو النسخ المؤرشفة تلقائيًا**؛ يلزم تقييم إزالة المعلومات الحساسة من سجل المستودع وتبعاتها، وفق صلاحيات الجهة المالكة، دون إعادة نشرها أو تكرارها في ملفات جديدة.

لا تضف أسماء ومعدلات تلاميذ أو أرقام تسجيل أو صورًا شخصية دون تفويض وأساس مناسب. لا توجد مصادقة أو قاعدة بيانات خاصة أو نموذج تواصل فعال في هذا الإصدار.

## قيد الاستكمال
هوية المؤسسة الإدارية، بيانات الهاتف والبريد الرسمي، الأخبار، الصور، الأنشطة، إحصاءات النتائج: تحتاج إلى مواد حقيقية معتمدة. يمكن إضافة لوحة إدارة آمنة لاحقًا عبر خدمة خلفية ذات صلاحيات نشر؛ GitHub Pages وحده لا يوفر مصادقة أو تخزينًا خاصًا.
