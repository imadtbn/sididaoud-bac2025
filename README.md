# البوابة الإلكترونية لثانوية حسين محمد الصغير – سيدي داود

موقع عام باللغة العربية، متوافق مع GitHub Pages، يخدم الأخبار والأنشطة والوثائق وأرشيف النتائج العامة.

## تشغيل الموقع
افتح `index.html` محليًا للصفحات الثابتة. لعرض بيانات JSON في المتصفح شغّل خادمًا محليًا، مثل `python -m http.server 8000` ثم افتح `http://localhost:8000/`.

## إضافة محتوى
توجد قوائم المحتوى في:
- `data/announcements.json`: الإعلانات
- `data/activities.json`: الأنشطة
- `data/documents.json`: الوثائق

صيغة السجل:
```json
{
  "title": "عنوان المادة",
  "date": "2026-10-15",
  "category": "عام",
  "summary": "وصف موجز",
  "url": "https://example.org/document.pdf",
  "published": false
}
```
يجب استبدال الرابط بمصدر معتمد. بعد التحقق من صحة المعلومات وموافقة الجهة المخولة، غيّر `published` إلى `true`. لا تُنشأ أخبار أو إعلانات وهمية في الموقع. يقبل الحقل `url` روابط http(s) فقط، ويمكن تركه فارغًا.

## التنقل
- `index.html`: الرئيسية
- `about.html`: من نحن
- `announcements.html`: الإعلانات والبحث والفلاتر
- `results.html`, `results-2025.html`: أرشيف البكالوريا العام
- `activities.html`: الأنشطة
- `students.html`: فضاء التلميذ
- `documents.html`: الوثائق
- `contact.html`: اتصل بنا
- `privacy.html`: سياسة الخصوصية

## تنبيهات الخصوصية
كان الإصدار القديم يحتوي في `index.html` على بيانات شخصية ونتائج فردية لطلبة 2025. النسخة الحالية لا تعرض تلك البيانات. لكن **إزالة المحتوى من آخر إصدار لا تمحو سجل Git أو النسخ المؤرشفة تلقائيًا**؛ يلزم تقييم إزالة المعلومات الحساسة من سجل المستودع وتبعاتها، وفق صلاحيات الجهة المالكة، دون إعادة نشرها أو تكرارها في ملفات جديدة.

لا تضف أسماء ومعدلات تلاميذ أو أرقام تسجيل أو صورًا شخصية دون تفويض وأساس مناسب. لا توجد مصادقة أو قاعدة بيانات خاصة أو نموذج تواصل فعال في هذا الإصدار.

## قيد الاستكمال
هوية المؤسسة الإدارية، بيانات الهاتف والبريد الرسمي، الأخبار، الصور، الأنشطة، إحصاءات النتائج: تحتاج إلى مواد حقيقية معتمدة. يمكن إضافة لوحة إدارة آمنة لاحقًا عبر خدمة خلفية ذات صلاحيات نشر؛ GitHub Pages وحده لا يوفر مصادقة أو تخزينًا خاصًا.

## بيانات العرض التجريبية (إضافة أكتوبر 2026)
تحتوي الملفات على **مواد خيالية بالكامل** لإظهار بطاقات الصفحات واختبار البحث والتصنيفات، ويُشار إلى ذلك في الواجهة بشريط واضح وبشارة "مثال تجريبي" على البطاقة:
- `data/announcements.json`: 9 إعلانات توضيحية.
- `data/activities.json`: 8 أنشطة افتراضية.
- `data/documents.json`: 6 وثائق نموذجية، منها رابطان لقالبين قابلين للطباعة داخل `samples/`.
- `data/results.json`: 3 سجلات **إحصائية افتراضية** لمواسم بكالوريا متعددة، دون بيانات شخصية. تُعرض في `results.html` وتفاصيل 2025.

### كيف تستبدل الأمثلة بمحتوى فعلي
1. افتح ملف القسم داخل `data/` وعدّل `title` و`date` (صيغة YYYY-MM-DD) و`category` و`summary`. وراجع الرابط `url` إن وجد.
2. احرص على تصنيف الإعلان ضمن الخيارات المتاحة في صفحة القسم ليعمل فلتر التصنيف بصورة صحيحة.
3. يظهر السجل فقط عندما تكون قيمة `published` هي `true`؛ استخدم `false` لإخفائه.
4. احتفظ بحقل `demo: true` على جميع الأمثلة. عند وضع مادة **حقيقية معتمدة للنشر** غيّر `demo` إلى `false` بعد موافقة الجهة المخولة.
5. نتائج البكالوريا في `data/results.json` تحتاج فقط إلى حقول `year` و`candidates` و`successful` مع `published` و`demo`. حساب النسبة تلقائي، ولا تُدخل أي اسم تلميذ.
6. **مهم:** يظهر شريط "نسخة تجريبية" تلقائيًا ما دام أي سجل منشور يحمل `demo: true`، ويختفي بعد إزالة جميع السجلات التجريبية المنشورة أو استبدالها بمحتوى معتمد يحمل `demo: false`. نموذجَا الوثائق قابلان للتعديل والطباعة وليسا استمارتين رسميتين.

ملاحظة: لا ينبغي اعتماد المحتوى الوهمي في أي إعلان حقيقي أو نتائج فعلية. الأرقام والأحداث والتواريخ أمثلة للاختبار فقط.
